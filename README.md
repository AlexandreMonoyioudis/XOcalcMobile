An item cost and craft value calculator for *Crossout* built for Android. Crossout items can be complex to price accurately due to resource costs and market fluctuations, so this mobile app was designed to simplify cost calculations on the go. Project is abbandonded due to developer no-longer playing Crossout.

---

## 💡 Overview & Features

* **True Cost Calculation:** Easily determine crafting costs and market values for items in *Crossout*.
* **Mobile-First Design:** Built as an Android app for quick access while playing.
* **Multi-Platform Support:** Solution structured to support both Android and Universal Windows Platform (UWP).

---

## 🛠️ Built With

* **Language:** C#
* **Framework:** Xamarin.Forms / .NET (Cross-Platform Mobile & UWP)
* **IDE:** Visual Studio / JetBrains Rider
